## 2.2.0

### 🚀 新功能

- **分类图标可选来源**（#90）：设置里新增「分类图标」——内置 SVG（默认，零请求）/ 首个站点图标（取该分类第一个启用站点的 favicon，加载失败自动退回）。配置页「交互」页和菜单条上的设置抽屉都能改，即时生效。
- **站点可达性检测**（#35）：站点页工具条新增「检测可达性」，用一次真实搜索请求探测当前分类的站点，没有响应的标红「不可达」，可一键隐藏（只改 `visible`，不删数据，能在「已隐藏」里找回）。

### 📱 移动端

- **设置抽屉**：窄屏下占满宽度，表单从「左标签 + 右控件」改成「标签在上」，单选组横向换行，内容区可滚动。之前 300px 抽屉里控件只剩 150px，「划词工具栏」这种 5 字标签会折行、4 个方向挤成 2×2、底部内容还被裁掉。
- **菜单条**：13 个分类按内容宽度排开 + 容器横向滚动——375px 下以前只能看到前 5 个，后面 8 个分类根本点不到。
- **下拉项**：高度 34px → 44px，字号 15px，手指不容易点错相邻项。

### 🐛 修复

- **配置页可能用默认值覆盖你的配置**：首屏把内置默认值当成了已读到的数据。没装油猴脚本时配置页要等 5 秒才拿到真实数据，这期间只要拖一下或点一下编辑，真实配置就再也铺不回界面，保存时会被默认值覆盖。现在读取期间整块内容锁住并提示「正在读取配置…」；同时记住「上次没连上油猴」，第二次访问不再干等。
- **JSON 编辑器保存会丢字段**：以前只保留 `nameZh / url / icon / data`，手写的 `invisible`、`style`、`selectors`、`query` 保存一次就没了。现在只剔除界面用的 `__uid`，其余原样保留；校验规则也和导入统一，不会再出现「导入成功、点保存被拒」。
- **触屏上分类点不动**：内部用一个标记记录「刚才点过」，但它永不复位——触屏点过一次，这个分类的点击就永久失效（点分类直达首个引擎、分类全开都用不了）。
- **划词工具栏开关反复切换会堆积监听**：三个全局监听从不移除，每切一次开关就多一份。
- **编辑中直接点保存**：提示「保存成功」，实际写的是旧名称/网址，状态条还一直显示「有未保存的修改」。
- **「加入常用」改一处动两处**：加入时放的是同一个对象，在「常用」里改名会连原分类一起改。
- **清除图标缓存后保存会复活**：保存时的合并只加不删，被清掉的图标又回来了。
- **反复进出 JSON 编辑页**：编辑器实例从不销毁，Ace 与内部监听会累积。
- **站点克隆头部后错位**：站点用 `cloneNode` 复制一个被我们推过的固定头部时，副本带着 `top: Npx !important` 却再也采不到，会永久错位。

### 🔍 数据

- 清掉 6 个实测失效的搜索源：大圣盘、大力盘、罗马盘（证书过期）、火山翻译（404）、爱问知识（已下线）、国家图书馆（搜索接口 500）。内置引擎 98 → 92。

### 🛠 工程

- 发版流程改成「先构建、再打 tag」：以前 tag 先推出去，CI 构建失败就无法重跑（同名 tag 已存在）。
- 产物检查开始认版本号：以前只要目录里有 zip 就算通过，实测 2.1.1 的包配 2.0.1 的产物也能全绿。现在校验文件名版本、manifest 的版本/权限/options 页、用户脚本的 `@version`/`@updateURL`/`@match`。
- 用户脚本只在发版 tag 上发布：以前每次 push master 都会把未发版的代码推到自动更新分支。
- 新增架构与质量 review 文档（`docs/architecture-review-2026-10-28.md`）。
