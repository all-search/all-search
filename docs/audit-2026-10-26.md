# 项目审计与迭代规划（2026-10-26）

> 一次只读审计的产出：文档与代码的偏差、产品/工程缺口、风险清单，以及按优先级排的迭代计划。
> 当时代码状态：`pnpm verify` 绿（21 个单测）、`pnpm audit` 0 漏洞、e2e 90 项全绿。
>
> 审计之后已经落地的部分，见文末「已完成」。

## 1. 结论

代码质量不是瓶颈，瓶颈在**发出去的过程**和**用户数据**：

1. 三条发布链路里两条「push master 就发布」，零门禁；
2. 配置只有一份存储，没有导出、跨上下文不同步，卸载即丢；
3. 文档有 13 处与代码不符，其中 2 处描述了根本不存在的功能（快捷键）。

## 3. 产品缺口（判断，不是清单）

| 能力 | 结论 | 理由 |
| --- | --- | --- |
| 配置导出/导入 | **做** | 配置是唯一用户资产，之前无导出、换形态带不走 |
| 跨上下文同步 | **做** | 设置页保存后已开页面不刷新就不变，用户以为没保存 |
| i18n | 不做 | 用户群中文；先修双语文档漂移更值 |
| 无障碍（全量） | 不做 | 菜单条鼠标优先；成本远高于收益 |
| Firefox MV3 | 不做（本迭代） | MV2 仍可装可签；切换要回归权限 + content script + options_ui |
| 扩展商店上架材料 | 不做 | 先决定是否上架；一旦上架，隐私政策要写清 favicon 外链抓取 |
| 版本升级提示 | 不做 | 油猴靠 `@updateURL` 自动升级；插件未上架；且会破坏设置页「零外链」设计 |
| 最小键盘入口 | 可做（P2） | 与文档冲突；只做一个全局唤起键，不做方向键导航 |

## 4. 工程缺口

- **e2e 没进 CI**：`plugin`/`selection` 依赖 `--load-extension`（Chrome 137+ 已移除），Linux 上只能跑 `userscript` + `config`。
- **`generatedStyle` 新鲜度**：扫描要外网 + 真浏览器，CI 不可复现；改为离线一致性单测。
- **发布流程**：`release.mjs` 只 stage `package.json`，工作区脏也照样打 tag。
- **runtime 体积已到平台期**：`el-table`/`el-cascader` 等在 chunk 里出现 0 次，按需引入有效，不要再压，改为防回退。

## 5. 风险

| 风险 | 说明 |
| --- | --- |
| WXT 0.21 的 Firefox 路径 | 升级后没人打过 Firefox 包；坏了只在发版当天暴露 |
| Node 版本 | wxt 0.21 要求 ≥ 22，workflow 却是 20 |
| `--load-extension` | `plugin`/`selection` 事实上只能在 Windows + Edge 跑，Edge 跟进后会一起失效 |
| 适配器误判 | 靠 `pathname.includes('options')` / `github.io` 猜身份 → 用户脚本在 github.io 子页会被当成配置站，静默写 localStorage |
